# 📈 Linear Regression Project

This project is a Machine Learning implementation of **Simple Linear Regression** using the Ordinary Least Squares (OLS) method.

## 📌 Project Overview
Using the dataset from Lecture 03, this Python script calculates the slope (\(\theta_1\)) and intercept (\(\theta_0\)) to find the "best fit line". It visualizes the regression line and the residuals (errors) using Matplotlib.

## 📂 Files in this Repository
*   `Linear_Regression_Project.ipynb`: The Google Colab notebook containing the mathematical explanations, Python code, and output graph.
